Why it matters — 02

What each place actually means

Same three stops as above — here's the plain-English version of each one.

working directory

Your actual files

The folder you edit in day to day. Git watches it but hasn't recorded anything about your changes yet — they're just sitting on your computer.

staging area

Your draft pile

A holding spot for changes you're about to save. git add moves a file here — it's how you choose exactly what goes into your next save point.

repository

Your permanent history

git commit locks the staged changes into history forever, with a message explaining what you did. You can always come back to this exact point.

Try it — 03

Commits form a timeline — branches let you fork it

Every commit is a save point, connected to the one before it. A branch is just a label pointing at one of those save points — which means you can try something risky without touching your main work. Build a small history below.

Keep this handy — 04

The commands behind everything above

Tap any command to see what it does. You now already understand what each one is for.

git init+
Turns the current folder into a Git repository, so Git starts tracking it.
git clone <url>+
Downloads a copy of a remote repository, history and all, onto your computer.
git status+
Shows what's changed, and whether it's staged or not yet staged.
git add <file>+
Moves a change from the working directory into the staging area.
git commit -m "<Your message here>"+
Saves everything in staging as a permanent point in your project's history.
git push+
Uploads your local commits to the remote repository so others can see them.
git push -u origin <branch>+
Pushes a new branch to the remote and remembers it, so future pushes just need git push.
git pull+
Updates your local copy of the repository from the remote source.
git branch <name>+
Creates a new label pointing at your current commit, so you can diverge safely.
git checkout <name>+
Switches which branch you're working on.
git merge <name>+
Brings another branch's commits into the one you're currently on.
git log+
Lists the commit history, oldest save points to newest.

You just learned the mental model that the entire rest of Git is built on. ◆ everything else is a variation on save, stage, and branch.
